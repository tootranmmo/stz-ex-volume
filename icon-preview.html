📄 SVG Source

ℹ️ Thông Tin

SVG icon là vector, có thể scale đến bất kỳ kích thước nào mà không mất chất lượng. Có thể chỉnh sửa và tạo lại PNG bằng script.

🔧 Tạo Lại Icon (Regenerate)

ℹ️ Cách Sử Dụng

Nếu muốn chỉnh sửa icon design hoặc regenerate PNG từ SVG, sử dụng script Python:

# Cài đặt Pillow (nếu chưa có)
pip install Pillow

# Tạo icon
python3 icon-generator.py

# Kết quả:
# ✓ extension/src/icons/icon-16.png
# ✓ extension/src/icons/icon-48.png
# ✓ extension/src/icons/icon-128.png
